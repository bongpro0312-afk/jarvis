# 자비스 설치 안내

## 1. Claude API 키 만들기 (5분, 한 번만)
1. https://platform.claude.com 에 가입하고 로그인해요.
2. 결제(Billing)에서 카드를 등록하고 크레딧을 충전해요. 처음엔 10달러 정도면 충분해요.
3. 월 사용 한도(Limits)를 20달러 정도로 걸어두면 요금이 넘칠 걱정이 없어요.
4. API Keys 메뉴에서 새 키를 만들고 `sk-ant-...`로 시작하는 값을 복사해 둬요. 이 키는 비밀번호처럼 남에게 보여주지 마세요.

## 2. 자비스를 인터넷 주소에 올리기
마이크를 쓰려면 `https://` 주소가 필요해요. 정해진 방법은 스레드 대화를 따라 주세요.

## 3. 아이폰에 설치
1. 사파리로 자비스 주소를 열어요.
2. 아래 공유 버튼 → "홈 화면에 추가"를 눌러요.
3. 홈 화면의 JARVIS 아이콘을 열고, 오른쪽 위 **설정**에 API 키를 붙여넣고 저장해요.
4. 가운데 원을 누르고 말하면 돼요. 처음에 마이크 허용을 물으면 "허용"을 눌러요.

## 4. 맥에 설치
- 크롬으로 열면 음성 인식이 가장 잘 돼요. 주소창 오른쪽 설치 버튼(또는 메뉴 → "페이지를 앱으로 설치")을 누르면 독(Dock)에 아이콘이 생겨요.
- 사파리라면 메뉴 "파일 → Dock에 추가"를 쓰면 돼요.
- 아이폰 설정을 그대로 옮기려면: 아이폰 자비스 설정에서 "설정 복사" → 메시지 앱의 '나에게 보내기' 등으로 맥에 옮김 → 맥 자비스에서 "설정 붙여넣기".

## 쓰는 법
- **가운데 원**: 누르면 듣기 시작, 말이 끝나면 자동으로 대답해요. 대답 중에 누르면 멈춰요.
- **연속 대화**: 켜두면 자비스가 대답을 끝낸 뒤 바로 다시 들어요. 손을 안 써도 대화가 이어져요.
- **"이거 기억해"**: 자비스가 설정의 "기억한 것"에 적어두고 다음 대화에서도 써요.
- **프로젝트 브리핑**: 허니봉, THE RAM 등 지금 진행 중인 일을 적어두면 자비스가 항상 알고 대답해요.
- **목소리 더 좋게**: 아이폰/맥 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성 → 한국어에서 "Yuna (향상됨)" 같은 고품질 음성을 내려받은 뒤, 자비스 설정에서 그 목소리를 고르세요.
